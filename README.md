# 터널프리

터널이 힘든 운전자를 위한 내비게이션입니다. 현대자동차그룹 차량용 앱 개발 공모전 출품작이고, Pleos Connect(Android Automotive) 위에서 돌아갑니다.

팀명: `미정이네` / 대표자: `오은세`


앱 설명:
공황장애나 폐소공포증이 있는 운전자는 터널에 들어갈 때 숨이 차거나 심장이 뛰곤 합니다. 그런데 기존 내비는 빠른 길만 알려 주고 터널을 얼마나 지나야 하는지는 말해 주지 않습니다. 터널프리는 터널이 얼마나 긴지, 오늘 몸 상태가 어떤지를 보고 피할지 지나갈지를 운전자와 함께 정합니다. 어쩔 수 없이 지나가야 하면 입구 앞에서 미리 말해 주고, 몸이 이상하면 차를 세우고 119를 부르도록 안내합니다.

## 앱이 하는 일

- 경로 판단: 가장 빠른 길과 터널을 피한 길을 같이 계산해서 "터널 꼭 피하기", "터널 꼭 지나가기", "직접 선택", "경로 차이 없음" 가운데 하나로 알려 줍니다. 터널 안에 머무는 시간을 기준으로 보고, 회피 강도는 모든 터널 / 300 m / 1 km / 3 km / 회피 안 함 중에서 고릅니다.
- 터널 안내: 입구 500 m 앞에서 미리 말하고(시속 75 km보다 빠르면 그만큼 더 앞에서), 3 km 넘는 터널 안에서는 남은 거리를 알려 줍니다. 입구 앞이 막히거나 조금 전에 불안하다고 알렸으면 다시 판단해서 우회를 제안합니다.
- 도움 버튼: "제가 불안해요", "제 몸이 이상해요", "같이 탄 사람이 아파요", "차에 문제가 있어요" 네 개입니다. 버튼 이름은 도움이 필요한 사람이 하는 말로 붙였고, 말로 해도 됩니다.
- 급정거 대응: 차량 신호나 가속도 센서로 급정거를 감지하면 "괜찮으세요?"라고 묻습니다. 12초 안에 답이 없으면 도로에 맞는 정차 방법을 알려 주고, 차가 서면 도움 화면을 엽니다. 에어백이 터지거나 주행 중 안전벨트가 풀리면 묻지 않고 바로 도움 화면을 엽니다. 앱이 브레이크나 핸들을 움직이지는 않습니다.
- 그 밖에 목적지 주변 주차장 안내, 음성 명령, 안심 음악과 호흡 안내가 있습니다.

## 실행 방법

제출과 시연 기준은 `pleos-app/`의 Kotlin 앱입니다. 루트의 `lib/`는 초기 Flutter 프로토타입이라 참고만 하면 됩니다.

### APK로 설치

`apk/미정이네_터널프리_release.apk`를 Pleos Connect Emulator나 Android 9(API 28) 이상 기기에 설치합니다. Pleos SDK를 쓰는 `pleos` 플레이버 빌드이고, SDK를 쓸 수 없는 환경에서는 Android 기본 음성·위치 기능으로 넘어갑니다. 에뮬레이터처럼 GPS가 경로 출발점 근처에 없으면 시속 60 km로 모의 주행합니다. 실제 시간으로 움직이니 긴 경로는 그만큼 오래 걸립니다. 터널만 빨리 보려면 메뉴의 "시연 목적지·터널 상태"에서 "실제 터널 통과 시연"을 누르세요. 약 2분 30초 걸립니다. 처음 켤 때 위치와 마이크 권한을 허용해 주세요. 설치 직후 첫 실행은 1~2분 걸리고 응답 없음 창이 뜰 수 있는데, 두 번째부터는 5초 안팎으로 뜹니다. 시연 전에 한 번 켜 두세요.

### 데스크톱 도구로 확인

PC 브라우저에서 앱과 같은 판단 로직을 돌려 보는 도구입니다. 제출 APK에는 들어가지 않습니다. Windows에서 `pleos-app\desktop\run-desktop.bat`을 실행하고 `http://localhost:8765`를 엽니다. 지도를 받아야 해서 인터넷이 필요합니다.

마우스 더블클릭이 목적지, `/`가 검색, `Enter`가 안내 시작, `Space`가 일시정지, `Esc`가 뒤로입니다.

### 소스에서 빌드

JDK 17~21(Android Studio에 들어 있는 JBR이 25이면 Gradle 8.14가 거부하니 JDK 21을 따로 쓰세요)과 Android SDK(compileSdk 35)가 필요합니다. API 키는 필요 없습니다.

```bash
cd pleos-app
./gradlew testStandardDebugUnitTest lintStandardDebug
./gradlew assemblePleosRelease
```

Windows에서는 `./gradlew` 대신 `.\gradlew.bat`을 씁니다. Android Studio로 열 때는 저장소 루트가 아니라 `pleos-app` 폴더를 여세요. `assemblePleosRelease`는 Pleos Maven 저장소에 접근할 수 있어야 하고, 저장소를 쓸 수 없으면 `./gradlew assembleStandardRelease`로 SDK 없는 빌드를 만들 수 있습니다.

프로젝트 경로에 한글이 있으면 Android Gradle Plugin이 빌드를 거부합니다. 사용자 이름이 한글이면 바탕화면이나 문서 폴더도 안 되니 `D:\work\tunnelfree` 같은 영문 경로에 두세요. Gradle 홈에 한글이 있으면 테스트 워커가 `ClassNotFoundException: GradleWorkerMain`으로 죽으니 `GRADLE_USER_HOME`도 영문으로 잡아 주세요.

### Flutter 프로토타입

`lib/kakao_config.dart`는 저장소에 없어서 예시 파일을 먼저 복사해야 합니다. 실제 지도를 띄우려면 [카카오 개발자 사이트](https://developers.kakao.com)에서 받은 JavaScript 키를 그 파일에 넣습니다. 키가 든 파일은 커밋하지 마세요.

```bash
flutter pub get
cp lib/kakao_config.example.dart lib/kakao_config.dart
flutter test
```

## 테스트 환경

| 항목 | 값 |
|---|---|
| 개발 도구 | Android Studio Ladybug 이상, JDK 17~21 |
| 빌드 | Gradle 8.14, AGP 8.7.3, Kotlin 2.0.21, Jetpack Compose |
| SDK | compileSdk 35, targetSdk 34, minSdk 28 |
| Pleos Connect 에뮬레이터 | Pleos Connect Emulator v2.1.0, 화면 2560×1440 (API 34) |
| 차량 화면 확인 | Automotive AVD, 1920×720, 160dpi |
| 실행 확인 | Pleos Connect Emulator v2.1.0(API 34, 2560×1440), Android Automotive 에뮬레이터(API 34, 1920×720) |
| 사용 SDK | Vehicle 2.3.2, FusedLocation 1.1.3, NaviHelper 3.0.5, TextToSpeech 3.3.1, SpeechToText 3.3.1 |
| 필요한 설정 | 첫 실행 때 위치·마이크 권한 허용. API 키 없음 |

지도, 도로망, 터널, 주차장, 시설은 OpenStreetMap(ODbL)의 대전 일대 자료입니다. 경로 계산은 앱에 들어 있는 도로망으로 하고, 지도 타일을 받을 때만 인터넷을 씁니다.

## 음성으로 쓰기

운전 중에는 화면을 보지 않아도 되도록 경로, 터널, 도움 안내를 음성으로 합니다. 왼쪽의 "음성" 버튼을 누르면 자주 쓰는 명령 25개가 버튼으로 나오고, 맨 아래 "마이크로 말하기"를 누르면 말로 명령할 수 있습니다. 명령 버튼은 말로 한 명령과 똑같이 동작합니다. 호출어("하이 OO" 같은 말)는 아직 없습니다.

앱이 먼저 물어보는 순간에는 질문이 끝나자마자 마이크가 저절로 켜지니 그냥 대답하면 됩니다. 음성 인식기가 준비되고 10초가 지나면 마이크는 꺼집니다. 그 전에 말을 알아들으면 바로 꺼집니다. "마이크로 말하기"로 켠 경우도 같습니다.

| 언제 | 이렇게 말하면 됩니다 |
|---|---|
| 목적지 | "대전역으로 가 줘", "한밭수목원까지 안내해 줘" |
| 경로를 고를 때 | "터널 피해서 가 줘", "1킬로 터널까지 허용", "다른 길로 가 줘" |
| 출발과 종료 | "안내 시작", "출발하자", "일시 정지", "안내 종료" |
| 터널 앞에서 우회를 물을 때 (자동) | "우회해 줘", "네", "그대로 가자" |
| 쉬어 가고 싶을 때 | "쉼터 들러 줘", "휴게소 들러 줘", "경유 취소" |
| 힘들 때 | "도와줘", "불안해요", "몸이 이상해요", "같이 탄 사람이 아파요", "차에 문제가 있어요" |
| 도움 화면 (자동) | "119 전화", "보호자 전화", "휴게소로", "호흡 안내", "닫아 줘" |
| 급정거 뒤 "괜찮으세요?" (자동) | "네, 괜찮아요", "도와줘" |
| 도착 뒤 터널 평가 (자동) | "괜찮았어요", "긴장됐어요", "힘들었어요", "건너뛰어" |
| 그 밖에 | "호흡 안내", "호흡 꺼", "음악 틀어 줘", "음악 꺼" |

119와 보호자 전화는 말로 해도 전화 화면까지만 열립니다. 통화 버튼은 사람이 누릅니다.

## 함께 작업할 때

- 브랜치를 따서 작업하고 PR로 올려 주세요. PR을 열면 CI가 `standard` 플레이버의 테스트, Lint, release 빌드를 돌립니다. `pleos` 플레이버는 전용 저장소가 필요해서 CI에서 빠져 있으니 Pleos 코드를 고쳤다면 직접 `compilePleosDebugKotlin`을 돌려 주세요.
- 판단 로직을 고치면 `domain/`에 단위 테스트를 같이 넣어 주세요.
- 외부 연동은 공모전이 허용한 Pleos SDK 5종(Vehicle, FusedLocation, NaviHelper, TextToSpeech, SpeechToText)까지만 씁니다. 외부 AI나 공공데이터 API를 넣고 싶으면 먼저 팀에서 얘기해 주세요.
- `lib/kakao_config.dart`, `key.properties`, `*.jks`는 올리지 않습니다.
- 수치를 바꿀 때는 근거 문서도 같이 고쳐 주세요. 터널 한도의 60초, 180초 같은 값은 임상 기준이 아니라 우리가 정한 설계값입니다. 발표할 때도 그렇게 말해야 합니다.

## SDK 사용 용도

앱 로직은 `platform/Ports.kt`의 인터페이스만 보고, 플레이버에 따라 구현이 바뀝니다. `pleos` 플레이버에서 SDK가 없거나 초기화에 실패하면 Android 기본 구현으로 넘어갑니다.

| 기능 | `standard` | `pleos` |
|---|---|---|
| 경로 안내 | 내장 도로망으로 계산 | 같은 계산. "차량 내비" 버튼을 누르면 NaviHelper로 목적지·경유지 전달 |
| 터널 접근·진입·이탈 | 경로 위치와 터널 DB로 판정 | 같은 판정에 FusedLocation 근접 알림(입구 반경 300 m)을 더함 |
| 음성 안내 | Android TTS | TextToSpeech |
| 음성 명령 | Android SpeechRecognizer | SpeechToText |
| 급정거 판정 | 가속도 센서 | 가속도 센서 + Vehicle (브레이크, 방향지시등, 조향, 에어백, 벨트, 주행거리로 추정한 속도) |

## AI 도구를 쓴 부분

코드 작성, 테스트, 문서 초안에 코딩 도우미 Claude Code를 썼습니다. 어떤 기능을 넣고 뺄지는 팀이 정했고, 커밋 기록에도 그대로 남아 있습니다.

앱 안에는 외부 AI나 대화형 언어 모델이 들어 있지 않습니다. 말을 글자로 바꾸고 글자를 말로 읽는 일만 Pleos SpeechToText와 TextToSpeech에 맡기고, 명령 해석과 경로 판단은 사람이 읽을 수 있는 규칙으로 돌아갑니다.

## 아직 못 한 것

- 실제 차량에서는 아직 돌려 보지 못했습니다. Pleos Connect Emulator에서 SDK 5종 초기화, Vehicle 신호 수신(에어백 리스너는 에뮬레이터의 Vehicle 서비스가 받아 주지 않았습니다), Pleos TTS 안내, Pleos STT 마이크 시작, NaviHelper 목적지 전달, 터널 시연 주행(접근부터 도착 뒤 평가 질문까지)을 확인했습니다. 음성 인식은 합성 음성을 가상 오디오 케이블로 넣어 4개 문구가 명령으로 인식되는 것까지 확인했고, 사람 목소리는 개발 노트북의 마이크 문제로 아직 시험하지 못했습니다.
- 정체 판정, 긴 터널 안내, 고속도로·터널 안 도움 화면, 전화 연결은 단위 테스트까지만 확인했습니다.
