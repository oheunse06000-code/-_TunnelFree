## 1. 현재 프로젝트 상태와 반드시 손봐야 할 점

현재 저장소: `https://github.com/KYU-SW/6-` (Flutter, `lib/main.dart` 1,610줄, 카카오맵 WebView + 체험용 도로망 + TTS/STT + 119 전화).

### 1-1. 플랫폼 불일치 (가장 중요)
공모전은 Pleos Connect SDK(Android 네이티브, Java/Kotlin) 를 전제로 하고, "기술 활용성" 항목이 Pleos SDK 활용도를 봅니다. 현재 앱은 Flutter이고 Pleos SDK를 전혀 쓰지 않습니다.

권장 방향 (12일 안에 현실적인 순서):
1. 1차 접수용: 지금 Flutter 앱으로 release APK + 시연 영상을 만들어 가산점을 확보한다. 기획서의 "개발 계획" 항목에 아래 SDK 매핑을 구체적으로 적는다.
2. 기획서·README에 Pleos SDK 적용 계획을 명시:
   - NaviHelper SDK → 목적지 설정·경로 추가/삭제로 터널 회피 경로 반영
   - FusedLocation SDK → 밀폐 구간 진입 판정 (현재 geolocator 대체)
   - TextToSpeech SDK → 안심 오디오 가이드 (현재 flutter_tts 대체)
   - SpeechToText SDK → 주행 중 음성 제어 (현재 speech_to_text 대체)
   - Vehicle SDK → 급제동·급감속 감지(공황 vs 교통상황 판단의 입력값), 비상등 등
3. 2차 PT 전까지(12/3): Pleos 에뮬레이터(https://document.pleos.ai/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator)에서 구동되는 형태로 전환. Flutter를 유지한다면 Android 쪽에 MethodChannel로 Pleos SDK를 붙이고, 어렵다면 핵심 화면만 Kotlin으로 포팅.

### 1-2. 저장소 정리 체크리스트

## 3. 시연 영상 제작 가이드

### 3-1. 사양 (규정 없음 → 권장값)
- 길이 2~3분 (심사위원이 끝까지 보는 길이), 최대 5분
- 1080p 이상, MP4(H.264), 가로 16:9. 차량 디스플레이 느낌을 주려면 Pleos 에뮬레이터 또는 가로 모드 녹화
- 업로드: YouTube "일부 공개(unlisted)" + 링크를 기획서와 README에 기재. 메일에는 파일도 첨부(25MB 이하로 압축) 또는 Google Drive 링크 병기, 이메일 제출이라 링크 하나만 믿지 말 것
- 한국어 내레이션 + 자막(음성 명령·TTS 내용은 반드시 자막으로 표시)
- 화면 녹화: Android Studio Logcat 옆 "Screen Record" 또는 `scrcpy --record demo.mp4`, 실기기는 기본 화면 녹화 + 내부 오디오 포함

### 3-2. 구성안 (심사 기준 4항목에 맞춤, 약 2분 40초)

| 시간 | 장면 | 보여줄 것 | 심사 기준 |
|---|---|---|---|
| 0:00~0:15 | 인트로 | 로고·앱 이름, "공황장애·폐소공포증 운전자 N만 명" 한 문장 문제 제기 | 창의성(Pain point) |
| 0:15~0:35 | 문제 상황 | 기존 내비가 터널 경로만 안내하는 비교 화면(목업 가능) | 차량특화성 |
| 0:35~1:05 | 기능 1 | 출발 전 "터널 회피" 토글 ON → 경로 재탐색 → 터널 0개 경로 표시, 지도 위 터널 구간 하이라이트 | 핵심 기능 |
| 1:05~1:30 | 기능 2 | 주행 중 음성 "터널 피해서 가 줘" → 인식 자막 → 경로 변경. 손을 쓰지 않는 조작 강조 | 차량특화성·기술 활용성 |
| 1:30~1:55 | 기능 3 | 터널 불가피 구간 진입 → 안심 오디오 가이드 재생(호흡 안내 등) + 남은 거리 표시 | 창의성 |
| 1:55~2:15 | 기능 4 | 급정거 감지 → 119 전화 화면. "공황 vs 교통상황 판별은 Vehicle SDK로 고도화 예정" 자막 | 기술 활용성 |
| 2:15~2:35 | Pleos 연계 | SDK 매핑 표 한 장(NaviHelper/FusedLocation/TTS/STT/Vehicle) | 기술 활용성 |
| 2:35~2:50 | 사업성·마무리 | 타깃(공황장애 진단 환자·운전 불안 운전자), 확장(보험·병원 연계), 팀 소개 | 사업성 |

### 3-3. 촬영 전 준비
- 체험 데이터임을 앱 화면에 노출하지 말고, 영상 자막으로 "프로토타입, 경로 데이터는 샘플" 한 번만 고지 (현재 앱의 "체험 데이터" 문구는 시연 모드에서 숨기거나 작게)
- 앱 라벨·아이콘을 `터널프리` 로 교체 후 녹화
- 음성 인식 장면은 조용한 곳에서, 실패 시 재촬영. TTS 음성은 기기 내부 오디오로 녹음되도록 설정
- 에뮬레이터 녹화 시 GPS는 Extended Controls → Location 으로 경로 재생

### 3-4. 편집 도구
- 무료: DaVinci Resolve, CapCut(PC), 클립챔프(Windows 기본)
- 자막·내레이션: 직접 녹음 또는 TTS(클로바더빙 등). 배경음악은 저작권 프리(YouTube 오디오 라이브러리)
